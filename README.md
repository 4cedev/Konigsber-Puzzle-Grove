# Königsberg Puzzle Grove

A fairy-themed Eulerian path puzzle game based on graph traversal and AI algorithms.

## How to Run Locally

1. Install Node.js (v18+ recommended)
2. Install dependencies:
   npm install
3. Run the development server:
   npm start
4. Open the browser at:
   http://localhost:1234

## Build for Deployment

To generate a production build:
npm run build

The output files will be generated in the `dist/` folder.

## Deployment

The game is deployed as a static web application using Vercel.
Parcel is used to bundle the project with relative asset paths to ensure compatibility with web hosting platforms.
